# Portfolio — LEMBASON Sitraka Lalaina

Portfolio personnel React + TypeScript + Vite, en français.

## Lancer le projet

1. Installer Node.js (version LTS).
2. Extraire le dossier.
3. Ouvrir un terminal dans le dossier `crock-portfolio`.
4. Exécuter :

```bash
npm install
npm run dev
```

5. Ouvrir l'adresse locale affichée par Vite (généralement http://localhost:5173).

## Avant publication : personnalisation obligatoire

Dans `src/App.tsx`, remplacer :
- `VOTRE_EMAIL@example.com` par l'adresse e-mail professionnelle.
- `https://github.com/VOTRE-PSEUDO` par le vrai profil GitHub.
- `https://www.linkedin.com/in/VOTRE-PROFIL/` par le vrai profil LinkedIn.

Ajouter ensuite les vrais liens de démonstration et dépôts GitHub des projets quand ils sont prêts.

## Vérification et build

```bash
npm run build
npm run preview
```

Les descriptions des projets sont volontairement prudentes : conserver les statuts exacts et ne pas présenter un prototype comme une application terminée.
